*Two complete, self-contained enterprise full-stack applications in a unified repository with automated GitHub Actions CI/CD pipeline.*

* **📦 Warehouse Inventory Management System** (Java 21 · Spring Boot 3.3.2 · React 18 · Vite · MySQL 8):
  - **Predictive AI Demand Forecasting Engine**: Computes 30-day consumption velocity, dynamic Reorder Points ($ROP = (\text{Demand} \times \text{Lead Time}) + \text{Safety Stock}$), and days-to-stockout depletion alerts.
  - **ACID Integrity & Concurrency**: JPA optimistic locking (`@Version` on `Product`) and transactional boundaries (`@Transactional`) preventing race conditions during high-concurrency checkouts.
  - **Automated Verification**: **19 Unit Tests** (JUnit 5, Mockito 5, AssertJ) covering authentication, stock decrements, ledger audit logging, and predictive calculations with **100% pass rate**.
  - **Enterprise Security**: Stateless JWT Bearer authentication, BCrypt encryption, and Role-Based Access Control (`ADMIN` vs `STAFF`).
  - **Containerization**: Multi-stage Dockerfiles and `docker-compose.yml` for unified local and production orchestration.

* **🎓 Academic Grade Management System** (Node.js · Express.js · React · MySQL · Sequelize):
  - Role-based grading portal with automated SGPA calculation, marksheet generation, and one-click semester result publishing.
