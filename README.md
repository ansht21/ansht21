## Analytics Approach

My workflow on every project:

1. **Frame the business question** before touching the data — what decision does the answer need to drive?
2. **Clean and validate** — deduplication, null audits, type casting, and engineered features with documented logic
3. **SQL warehousing** — schema design, bulk load, and layered analytical queries from KPI roll-ups to window-function deep dives
4. **Python EDA** — distribution checks, correlation matrices, and visualisations that either confirm or challenge the initial hypothesis
5. **BI delivery** — a Power BI or Excel dashboard built for the stakeholder, not the analyst
